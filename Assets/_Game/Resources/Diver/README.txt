CaveDive diver art drop-in folder

FASTEST OPTION (recommended first)
1. Put one transparent side-view diver PNG here.
2. Name it exactly: diver_full.png
3. Diver should face RIGHT in the source image.
4. Unity will auto-import it as a Sprite.
5. Play the scene. The prototype block diver is replaced automatically.

MODULAR OPTION (optional)
You can instead add any of these transparent PNGs:
- diver_body.png
- diver_tank.png
- diver_head.png
- diver_fin_top.png
- diver_fin_bottom.png
Optional:
- diver_arm.png
- diver_lamp.png

The runtime replaces only the parts that exist. Missing parts keep the prototype fallback.
The two fin parts receive a small procedural kick animation while swimming.

ART DIRECTION
- Side view, horizontal swimming pose
- Realistic or semi-realistic cave/scuba diver
- Dark wetsuit/drysuit
- Tank, mask/regulator and fins clearly readable
- Transparent background
- Avoid baked flashlight beams/background lighting in the PNG
- Keep the lamp itself as part of the art, but the actual game light is generated by Unity
